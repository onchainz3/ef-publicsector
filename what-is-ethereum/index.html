What is Ethereum?

Ethereum is an open, public blockchain network that people and organizations can use to keep shared digital records and run programs. No single organization operates or controls the network.

Ethereum is a public blockchain network, while ether (ETH) is the cryptocurrency used to pay transaction fees and help secure the network. Institutions can incorporate Ethereum into their digital infrastructure without requiring people who use their services to purchase or hold ETH.

Key characteristics of the network

These characteristics shape how Ethereum can be used as digital public infrastructure:

  • Free to use and build on

    Anyone can use Ethereum or build on it. There is no central owner or operator that decides who can access the network.

  • Developed transparently

    Ethereum’s core software is open source and maintained by independent teams. Anyone can inspect, use, and contribute to the code.

  • Programmable shared infrastructure

    Ethereum also supports smart contracts: programs that run on the network and carry out actions according to rules written into software.

Where the Ethereum Foundation fits

The Ethereum Foundation (opens in a new tab) is a nonprofit working to strengthen Ethereum's resilience. It is part of a larger community of organizations and individuals that grow the ecosystem, support protocol development, and advocate for Ethereum. The EF does not operate, control, or own the network.

How Ethereum works

Ethereum is a global network of independently operated computers, called nodes. Together, these nodes maintain a shared digital record and run programs. A request to update or change the shared record is called a transaction. Nodes check each transaction against Ethereum’s common rules and agree on which valid updates become part of the shared record.

A shared record that can be independently verified

The shared record serves a purpose similar to a database, but is maintained across independently operated computers rather than controlled by a single institution.

Because independent nodes maintain the same history, people and institutions can verify it without relying on a central operator.

Validators stake ETH to secure the network

The nodes that propose new blocks and vote on which ones become part of the shared record are called validators. To take part, a validator must lock up, or stake, at least 32 ETH, Ethereum’s native currency, as a deposit. Validators earn rewards for doing this work correctly.

If a validator breaks the rules in a way that could harm the network, such as approving two conflicting versions of the record, part of its stake is destroyed and it is removed from the network. This is called slashing. Because misbehaving costs real value, validators have a financial reason to follow the rules.

Programmable shared infrastructure

Ethereum can run programs called smart contracts. The rules a smart contract follows are defined by the people or organizations that design it, including the conditions that must be met and the actions to take when they are met. When triggered by a transaction, a smart contract applies those rules and can, for example, transfer funds or update a shared record.

  1. 1 Define the rules

    People or organizations define the conditions a smart contract checks and the actions it takes when those conditions are met

  2. 2 Send a transaction

    A person or application sends a request that triggers the smart contract

  3. 3 Run the program

    The smart contract checks the conditions and carries out the specified action if they are met

  4. 4 Record the result

    The result becomes part of Ethereum’s shared record
